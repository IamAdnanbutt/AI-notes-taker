# ICT Concept Detection Rules

Flag a timestamp and capture a screenshot whenever the transcript or video
contains ANY of these ICT concepts.

## Price action concepts

| Concept | Also watch for |
| --- | --- |
| FVG / IFVG / Inversion FVG | Breaker Block |
| Order Block (Bullish / Bearish) | Mitigation Block |
| Balanced Price Range (BPR) | Rejection Block |
| Propulsion Block | Vacuum / Void |
| Buy-Side Liquidity (BSL) | Sell-Side Liquidity (SSL) |
| Equal Highs / Equal Lows | Previous Day High/Low |
| Market Structure Shift (MSS) | Change of Character (CHoCH) |
| Premium / Discount (50% level) | Optimal Trade Entry (OTE) |

## Time & session concepts

- Silver Bullet Window (10–11 AM / 2–3 PM / 3–4 AM ET)
- London Kill Zone (2–5 AM ET)
- NY AM Kill Zone (7–10 AM ET)
- NY PM Kill Zone (1:30–4 PM ET)
- Asian Range / Asian Session High-Low
- Power of 3 (PO3) / Accumulation–Manipulation–Distribution
- Midnight Open / NY Midnight Open
- True Day Open (00:00 / 8:30 AM ET)

## Trade management concepts

- Entry confirmation / Trigger candle
- Stop Loss placement (below OB / above FVG / beyond sweep)
- Partial close / Scale out
- Daily Objective Levels (DOL)
- ADR (Average Daily Range) projection
- Risk:Reward setup (minimum 1:2 required)

## Presenter cues (always flag)

- A chart is being shown or drawn on screen
- A trade entry, stop loss, or take profit is being marked
- A backtesting or live trade example is being reviewed
- Phrases: "look at this", "here you can see", "notice", "this is important"
