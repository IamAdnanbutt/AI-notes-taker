# Screenshot Annotation Legend

Every annotated screenshot must use this exact color code. Draw labels,
arrows, and boxes directly on the captured frame (via `scripts/annotate.py`),
and attach a short text label to every mark.

| Mark | Meaning |
| --- | --- |
| BLUE box | Fair Value Gap (FVG) |
| RED box | Bearish Order Block (OB) |
| GREEN box | Bullish Order Block (OB) |
| YELLOW arrow | Liquidity Sweep (BSL or SSL) |
| ORANGE line | Market Structure Shift (MSS) |
| PURPLE zone | Kill Zone window |
| WHITE line | Entry price |
| RED dashed line | Stop Loss |
| GREEN dashed line | Take Profit / Target |
| GREY zone | Premium or Discount level (above/below 50% equilibrium) |

Mark ALL visible ICT concepts on each frame: FVG, OB, BSL/SSL, MSS, BPR, PO3
phases, Kill Zone windows, Premium/Discount zones, sweep candles, and entry /
SL / TP levels.
